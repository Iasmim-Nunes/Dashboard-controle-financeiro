# Dashboard de Controle Financeiro

Painel de orçamento pessoal mês a mês, feito em um único arquivo HTML. Não precisa instalar nada: é só abrir o `index.html` no navegador.

## Como usar

1. Baixe o `index.html` (ou clone o repositório) e abra no Chrome, Edge ou Firefox.
2. Em **Configurações › Seu nome**, coloque o seu nome.
3. Escolha o mês no topo (‹ Setembro ›) e clique em **Editar mês** para lançar:
   - o planejamento do mês (receitas, despesas, meta de investimento e resultado);
   - o que foi realizado (receitas, investimentos, contas a pagar e a receber);
   - os gastos por categoria.
4. Use **Copiar planejamento do mês anterior** para não redigitar o orçamento todo mês.

## Telas

- **Dashboard**: resumo do mês, pendências, gráfico de receitas e despesas dos 12 meses, despesas por categoria e metas.
- **Receitas**, **Despesas**, **Orçamento**, **Investimentos** e **Contas a pagar**: visão do ano, mês a mês.
- **Configurações**: nome, troca de conta, backup e opção de zerar os dados.

## Onde os dados ficam

Os valores ficam salvos no próprio navegador (localStorage), no computador de quem usa. Nada é enviado para a internet.
Para não perder os dados ao limpar o navegador ou trocar de computador, use **Configurações › Backup › Exportar** e depois **Importar**.

Dá para ter mais de uma conta (por exemplo, uma para cada pessoa da casa) clicando no nome no menu lateral.
